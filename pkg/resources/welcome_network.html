Tiles is a local-first private AI for everyday use. Runs on-device models with encrypted P2P sync, and support for sharing chats publicly on ATProto.

This setup installs the Tiles runtime and required dependencies. During onboarding you will be prompted to download a model.

Tiles installs its CLI and runtime in /usr/local so that it is available system-wide. MacOS will request administrator authorization (password or Touch ID) to allow this installation.
