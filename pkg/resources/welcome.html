Tiles is a local-first private AI assistant for everyday use. Runs on-device models with encrypted P2P sync, and supports sharing chats publicly on ATProto.

This setup installs the Tiles runtime, dependencies, and the default gpt-oss-20b model so the system works fully offline with no additional downloads.

Tiles installs its CLI and runtime in /usr/local so that it is available system-wide. MacOS will request administrator authorization (password or Touch ID) to allow this installation.
