This setup installs the Tiles app, runtime, dependencies, and the default Gemma 4 12B model so the system works fully offline with no additional downloads.

Tiles installs its CLI and runtime in /usr/local so that it is available system-wide, and the Tiles app in /Applications. MacOS will request administrator authorization (password or Touch ID) to allow this installation.
